# Raspberry Pi Game Boy

Production files for Raspberry Pi-based handheld gaming consoles.

The first version is based on the **Raspberry Pi Pico** and is designed to run retro **Game Boy (`.gb`) games**.

The second version is based on the **Raspberry Pi Zero** and supports **Game Boy Advance (`.gba`)**, **Game Boy Color (`.gbc`)**, and **Game Boy (`.gb`)** games.

Each project folder includes the complete set of files needed to reproduce the hardware, including:

- Schematics
- PCB / production files
- Firmware
- Supporting project files

These folders are intended to contain everything required to build and reproduce each console.
